Arrhenius.jl

Arrhenius.jl provides Julia-native tools for chemical kinetics and reacting-flow calculations. It reads Cantera YAML mechanisms and uses preprocessed sidecar files for kinetic and transport data. Cantera is not required at calculation time.

Start here

  • Installation explains how to add the package and prepare a mechanism.
  • Mechanisms describes supported mechanism data and sidecars.
  • Zero-dimensional reactors introduces ignition calculations and ODE solver integration.
  • One-dimensional flames covers flame types, transport, and discretization.
  • Solver options documents refinement, time stepping, and transport controls.
  • Examples indexes runnable examples by application.
  • Validation methods explains code-parity and solution-accuracy comparisons.
  • API reference lists exported types and functions.

Capability overview

The package includes ideal-gas thermochemistry, kinetics, equilibrium and sound-speed calculations; constant-pressure and constant-volume reactors; reactor networks; planar and opposed-flow flames; catalytic and ionized models; transport, plasma, porous-media, pure-water, and real-gas tools. See the examples index for entry points.
