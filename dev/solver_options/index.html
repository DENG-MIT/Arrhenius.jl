Solver options

Spatial discretization

FreeFlame and BurnerFlame accept :finitedifference and :conservative. The constructor default is :finitedifference. Set discretization=:conservative to use finite-volume species and total-enthalpy balances. Ionized flames also accept both options; their initial conservative solve first uses a frozen finite-difference stage.

Grid refinement and solve controls

solve! adaptively refines a grid by default. Common controls are:

  • ratio, slope, and curve: refinement thresholds.
  • prune: remove points whose indicators fall below the threshold; 0 disables pruning.
  • maxpoints and maxtime_steps: bounds for the solve.
  • initialtimestep, timestepgrowthfactor, and timestepgrowthstrategy: pseudo-time stepping controls.
  • timestepcallback and timestepregrid: observe or recover from stalled time stepping.
  • jacobianmode=:auto or :finitedifference: use the analytic or numerical Jacobian path where available.
  • auto=true: for FreeFlame, use a staged solve and domain expansion; counterflow solvers use their own recovery sequence.

Refinement settings and supported controls vary by flame family. Consult the corresponding constructor and solve! docstrings in the API reference.

Transport

settransport!(flame, :mixtureaveraged) selects mixture-averaged diffusion. :multicomponent requires MultiTransportData exported from the same mechanism. Set soret=true to include thermal diffusion; this also requires matching multicomponent data. For mixture-averaged transport, fluxgradientbasis=:mole or :mass chooses the gradient basis.

Counterflow diffusion flames can enable optically thin radiation with set_radiation!. Radiation and transport options apply only to flame families that expose them.
