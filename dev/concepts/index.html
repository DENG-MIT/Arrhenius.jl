About the package

Arrhenius.jl is a Julia package for reacting-flow and combustion modeling, including differentiable chemistry workflows.

Related projects

  • ArrheniusActiveSubspace: sensitivity analysis and uncertainty quantification.
  • ArrheniusFlame1D: one-dimensional flame sensitivity analysis.
  • CRNN_HyChem: neural-network approaches to learning kinetic mechanisms.
  • DeepReduction: mechanism reduction workflows.

Related software includes Cantera for mechanism processing and reference calculations and ReactionMechanismSimulator.jl for chemical mechanism simulation.
