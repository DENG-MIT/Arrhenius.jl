Numerical design rationale

This page records numerical choices visible in audited Arrhenius.jl and Cantera source paths, the reasons available in source history, and tests identified by the audits. It is a source comparison, not a claim that the solvers produce identical solutions.

Scope. Arrhenius.jl refers to audited source snapshot 78ab438, flame mode discretization=:finite_difference, except where point APIs/reactors are named. Cantera refers to 4.0 development source at commit 726522be4e2a13454d8415b7ef799d621f665cf3, with mixture-averaged transport and no Soret/radiation by default. Cross-code survey: 2026-10-16. “Identical” means same rule/constants in the audited mode, not bitwise equality; “different” describes implementation, not merit. All comparison code references below are public.

Many original Cantera constants predate surviving issue/PR records. Where motivation cannot be established, it is stated as unknown rather than inferred. Cantera's original 1-D solver cites Kee, Coltrin, and Glarborg’s Chemically Reacting Flow (publisher record). Cantera line links are pinned to the source SHA. Tests are those identified in the audits; “none found” means no dedicated test was located.
